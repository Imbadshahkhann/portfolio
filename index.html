🧃 OWASP Juice Shop - Complete VAPT Assessment

Web Application Security Testing Lab

🎯 Problem Statement

Identify and exploit critical vulnerabilities in a deliberately insecure web application to understand real-world attack vectors and defensive strategies.

🛠️ Environment Setup

  • ✓ Deployed OWASP Juice Shop on local Kali Linux VM
  • ✓ Configured Burp Suite as intercepting proxy
  • ✓ Set up Wireshark for traffic analysis
  • ✓ Prepared logging and documentation framework

⚔️ Attack Simulation & Discovery

SQL Injection: Bypassed authentication by injecting admin' OR '1'='1' -- into login form. Successfully gained admin access without credentials.

Cross-Site Scripting (XSS): Injected malicious JavaScript payload in search field. Successfully executed arbitrary code in victim's browser context.

Broken Access Control: Manipulated user ID parameters to access other users' order history and personal data.

Security Misconfiguration: Discovered exposed admin panel at /administration endpoint due to improper access controls.

📊 Detection Logic & SIEM Query

Detection Rule for SQL Injection:

source="web_access_logs" | search "OR '1'='1'" OR "' OR 1=1--" | stats count by src_ip, user_agent | where count > 3

🔍 Investigation Process

  1. Intercepted HTTP requests using Burp Suite
  2. Analyzed request/response patterns for anomalies
  3. Documented each vulnerability with screenshots and PoC
  4. Mapped findings to OWASP Top 10 categories
  5. Created structured remediation recommendations

✅ Outcome

✓ Identified 12 critical and high-severity vulnerabilities
✓ Generated comprehensive 15-page security assessment report
✓ Provided actionable remediation steps with code examples
✓ Demonstrated end-to-end penetration testing methodology

🕵️ Keylogger Detection System - Behavioral Analysis

Endpoint Threat Detection & Forensics

🎯 Problem Statement

Develop a Python-based detection system to identify unauthorized keylogger processes running in the background, simulating EDR (Endpoint Detection & Response) capabilities.

🛠️ Environment Setup

  • ✓ Windows 10 VM for testing environment
  • ✓ Python 3.x with psutil library for process monitoring
  • ✓ Sample keylogger binaries for testing (ethical lab use only)
  • ✓ Configured logging for process behavior tracking

⚔️ Attack Simulation

Deployed a benign keylogger in a sandboxed environment to simulate adversary behavior. The malware attempted to:

  • Hook keyboard input events
  • Write captured keystrokes to hidden log files
  • Run as a background service without UI
  • Establish persistence through registry modification

📊 Detection Logic

Rule-based detection approach:

Detection Criteria:

  • Processes with no visible window but high CPU usage
  • Unsigned binaries running from unusual directories (temp, appdata)
  • Processes accessing keyboard input APIs
  • Suspicious file write operations to hidden directories

🔍 Investigation Process

  1. Enumerated all running processes using psutil
  2. Filtered processes by behavior patterns (no GUI, file writes)
  3. Analyzed process command-line arguments for suspicious strings
  4. Cross-referenced with known legitimate system processes
  5. Triggered alerts for anomalous process behavior

✅ Outcome

✓ Successfully detected keylogger process with 100% accuracy
✓ Reduced detection time to under 5 seconds
✓ Demonstrated understanding of EDR behavioral analytics
✓ Created foundation for advanced endpoint monitoring

Python psutil Malware Detection Endpoint Security Behavioral Analysis T1056.001 - Input Capture: Keylogging T1547 - Boot or Logon Autostart

📧 ML-Based Email Spam Detection - Phishing Defense

Machine Learning for Threat Detection

🎯 Problem Statement

Build an intelligent email classification system using Natural Language Processing (NLP) to automatically detect phishing and spam emails, enhancing security awareness programs.

🛠️ Environment & Tools

  • ✓ Python with scikit-learn, pandas, NLTK libraries
  • ✓ Email dataset (5,000+ labeled samples: spam vs legitimate)
  • ✓ Trained using Naive Bayes and Random Forest algorithms
  • ✓ Feature engineering: word frequency, suspicious keywords, sender patterns

📊 Detection Methodology

NLP Pipeline:

  1. Text preprocessing (tokenization, stemming, stop-word removal)
  2. Feature extraction using TF-IDF vectorization
  3. Trained classifier on labeled dataset
  4. Real-time email scanning and classification

Phishing Indicators Detected:

  • Urgent action requests ("verify account immediately")
  • Suspicious URLs and domain mismatches
  • Generic greetings ("Dear Customer")
  • Requests for sensitive information (passwords, SSN)

✅ Outcome & SOC Integration

✓ Processed and classified emails in <2 seconds
